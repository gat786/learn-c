6. Call by value and call by reference
    But the finer detail to know is that, when a function is called `c` passes
    the arguments as values. Meaning in the function that is called the
    arguments are temporary variables accessible to them, so if the function modifies it changes in a way. It is okay, outside of the function scope the
    variable stays intact. You can pass a value as a reference by using pointers.

    Arrays are passed as references. Make note of that.
